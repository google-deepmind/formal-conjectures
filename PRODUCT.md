# FC contribution surfaces

## Register

product

## Users

Mathematicians, Lean contributors, maintainers, and coding agents inspect an exact
statement, its sources, related work, and evidence before deciding what to do next.

## Product Purpose

Lean sources and Lake pins define statements. Publish one native catalog for the
website, CLI, and repository checks; use Verso only for rendering from the same
build. See [the static data contract](site/API.md). The contribution toolkit supplies
advisory reviews and exact-target verification records. The website presents those
records without deciding mathematical status or maintainer acceptance.

## Brand Personality

Precise, readable, restrained. Use FC's existing site components and terminology.

## Design Principles

- Preserve the current website design and theme choices.
- Show the exact declaration and revision to which evidence applies.
- Keep conditional proofs, variants, review coverage, and acceptance distinct.
- Retain historical results and corrections without presenting them as current.
- Give a contributor one clear next action and a copyable CLI handoff.

## Accessibility & Inclusion

Use semantic headings, ordinary links, visible keyboard focus, and readable status
text. Status must remain understandable without color. Preserve existing light and
dark themes; this change does not add motion or new navigation.
