# Reflective cell checker for the order-19 Krein certificate (L = 4/5)

`checkCell pa c breaks : Bool` computes, in exact rational arithmetic, a Taylor model of the
weighted cell budget on each piece of a cell and compares its floor with its error.
`checkCell_sound` turns `checkCell pa c breaks = true` into `CellAnalyticSoundV1 c`. Every cell is
then closed by one `decide +kernel`.

| Module | Content |
|---|---|
| `RHKreinTaylorModelV1` | `Poly`, `TM`, `Encl`, arithmetic, `trim` with outward rounding |
| `RHKreinTrigTMV1` | cos/sin/sinc Taylor models, halving–doubling phases |
| `RHKreinRotTMV1` | complex phase enclosures `ZEncl`, rotation `rotC` |
| `RHKreinHatFastV1` | one hat column from a phase (`col_encl`) |
| `RHKreinSymbolLowerQV1` | rational floor of the symbol from a left end point |
| `RHKreinCellCheckerV1` | `checkCell`, `checkCell_sound` |
| `RHKreinCellBatchV1` | `checkAll`, slices |
| `RHKreinAllCellsV1` | assembly of cells 0–2198 (generated by `tools/genassembly.py`) |

Cells 15–2198 are checked in 219 generated batch modules (`tools/genbatch2.py`, breakpoints from
`tools/val2{A,B}.json`, one theorem per cell, parameters `pa19 = ⟨⟨14,30,11,120⟩,10,120,16⟩`).
`tools/mirror.py` is an exact `Fraction` mirror of the checker.

Status at this commit (2026-10-05): all 219 batches pass in the kernel (Lean 4.33.1, Mathlib `0df444a`).
`RHKreinAllCellsV1` compiles; `allCellsAnalyticSound` and `zero_quadratic_margin_two_fifths`
(`(1/16)·E ≤ Re Σ_ρ Z_ρ` for every moment-zero packet of log-half-width `r ≤ 2/5`) depend on
`[propext, Classical.choice, Quot.sound]`. The chunk lemma is applied with an explicit predicate
(`refine mem_of_chunks (fun c => CellAnalyticSoundV1 c) 10 219 (finiteCells.drop 15) ?_ ?_`).
